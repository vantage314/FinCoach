# 20260203_注册登录联调修复记录

## 1. 为什么之前控制台没日志
- **配置覆盖**: 之前的 `application.yml` 日志级别设为 `info/debug` 过于宽泛，且未指定 `org.mybatis` 等具体包的日志级别。
- **构建同步**: 核心原因是 JDK 版本冲突导致 `mvn compile` 失败，后端一直运行的是旧版本的字节码，导致配置变更未能生效。
- **修复**: 通过 `root: INFO` + 明确的微调包级别，并引导用户使用 IDE 重建项目。

## 2. 为什么数据不入库
- **旧代码运行**: 旧版本的 `AuthController` 是空实现（Mock 成功），导致请求未触达数据库逻辑。
- **主键/时间戳策略**: 数据库设置了 `AUTO_INCREMENT`，但手动设置 `createTime` 可以防止部分 MyBatis Plus 配置下出现的 null 值插入异常。
- **修复**: 在 Service 层显式捕获插入行数并打印，若不入库则强行抛出运行时异常。

## 3. 前端反馈优化
- **拦截器干扰**: 修正了前端错误捕获逻辑，确保后端异常能通过 `catch` 块被 `ElMessage` 正确捕捉。

## 4. 最终状态
- 后端已添加 `System.out` 这种不可屏蔽的调试日志。
- 后端已添加 `/api/auth/test` 连通性测试接口。
- 前端注册失败时会有显式红色弹窗提示。
