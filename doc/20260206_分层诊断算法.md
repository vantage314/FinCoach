# 智能投顾算法与分层诊断逻辑文档

## 1. 核心设计理念
本系统采用 **"双轨制分层诊断 (Dual-Track Diagnosis)"** 与 **"资金同源闭环 (Closed-Loop Execution)"** 两大核心机制，旨在解决传统智能投顾"不懂用户"和"执行断层"的痛点。

## 2. 用户画像探测器 (User Persona Detector)
系统根据用户持仓结构自动判定用户类型：

| 用户类型 | 判定规则 | 适用场景 |
| :--- | :--- | :--- |
| **🔰 储蓄型用户 (NOVICE)** | 持有 `金融投资` 类资产金额 = 0 | 刚起步理财，资产集中在现金或房产，抗通胀能力弱。 |
| **📈 进阶投资者 (INVESTOR)** | 持有 `金融投资` 类资产金额 > 0 | 已尝试股票/基金/理财，需要优化持仓结构与风险控制。 |

## 3. 双轨制评分模型

### 3.1 小白模式 (Novice Mode)
*   **基准分**：60分
*   **扣分项**：无投资资产 (-10分) —— 警示长期跑输通胀风险。
*   **加分项**：应急准备金充足 (> ¥30,000) (+20分) —— 鼓励先存钱后理财。
*   **展示重点**：**闲钱激活潜力图** (对比 现金收益 vs CPI vs 理财目标)，直观展示购买力缩水风险。

### 3.2 进阶模式 (Investor Mode)
采用四维健康模型：
1.  **流动性 (20分)**：现金类资产占比 (理想值 10%~20%)。
2.  **风险匹配 (40分)**：权益类仓位 vs 风险测评等级 (如平衡型建议权益 40%)。
3.  **保障力 (20分)**：由于暂无保险数据，目前主要参考固定资产作为兜底。
4.  **分散度 (20分)**：持有的资产大类数量 (>3类为优)。

## 4. 限制性计划生成 (Constrained Planning)
为防止用户"借钱炒股"或"透支生活费"，系统引入资金约束：

*   **最大可投金额 (Max Investable)** = `总现金资产` - `应急准备金 (默认3万)`
*   **警告机制**：
    *   若用户输入投入金额 > Max Investable，系统**允许生成**计划，但会插入一条 **WARNING** 级别的风险提示。
    *   提示内容："⚠️ 您的投入金额(¥50,000)已超过建议的闲置资金(¥20,000)，建议保留至少 ¥30,000 作为应急储备。"

## 5. 科学执行逻辑 (Scientific Execution)
解决"一键执行"后资产凭空增加的问题：

1.  **买入 (BUY)**：
    *   **增加** 目标资产 (如 沪深300ETF)。
    *   **扣减** 现金资产 (自动寻找金额最大的现金账户进行扣款)。
    *   *异常处理*：若现金不足，阻断执行并报错。
2.  **卖出 (SELL)**：
    *   **减少** 目标资产。
    *   (逻辑待补充：卖出所得资金应自动转入现金账户，当前版本暂未实现自动回款，默认为场外操作)。
