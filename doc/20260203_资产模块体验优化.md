# 20260203_资产分类简化与子类型支持

## 1. 新分类结构
| ID | 分类名称 | formType | 描述 |
|:---|:---|:---|:---|
| 1 | 现金 | SIMPLE | 银行卡、支付宝、微信余额 |
| 2 | 金融投资 | INVEST | 股票、基金、债券 |
| 3 | 固定资产 | PROPERTY | 房产、车辆 |

### formType 说明
- **SIMPLE**: 仅填写名称 + 金额
- **INVEST**: 必须选择子类型（股票/基金/债券），可填成本/代码
- **PROPERTY**: 填写名称 + 金额，可填成本

## 2. 子类型映射
```
金融投资 (categoryId=2)
├── 股票
├── 基金
└── 债券
```

后端校验逻辑：
```java
if (dto.getCategoryId() == 2 && (dto.getSubType() == null || dto.getSubType().isBlank())) {
    throw new IllegalArgumentException("金融投资类必须选择子类型（股票/基金/债券）");
}
```

## 3. 前端交互设计
1. **第一行**: `el-radio-group` 按钮样式展示三大类
2. **第二行**: 选中"金融投资"时显示子类型选择器
3. **提交按钮**: 金融投资类未选子类型时禁用

## 4. 数据库变更
```sql
-- 新增 sub_type 字段
ALTER TABLE asset_item ADD COLUMN sub_type VARCHAR(50) DEFAULT NULL;
```
