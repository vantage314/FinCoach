# 20260203_全量数据库建模

## 1. 用户表 (user)
用于存储系统用户信息。

| 字段名 | 类型 | 约束 | 描述 |
| :--- | :--- | :--- | :--- |
| id | bigint | PK, AUTO_INCREMENT | 唯一标识 |
| username | varchar(50) | UNIQUE, NOT NULL | 用户名 |
| password | varchar(100) | NOT NULL | BCrypt 加密后的密码 |
| email | varchar(100) | | 电子邮箱 |
| phone | varchar(20) | | 手机号码 |
| create_time | datetime | DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| update_time | datetime | DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP | 更新时间 |

## 2. 资产分类字典 (asset_category)
定义资产的分类。

| 字段名 | 类型 | 约束 | 描述 |
| :--- | :--- | :--- | :--- |
| id | int | PK, AUTO_INCREMENT | 唯一标识 |
| name | varchar(50) | NOT NULL | 分类名称 (现金/固收/权益/保障/其他) |
| icon_slug | varchar(50) | | 图标标识符 |
| description | varchar(255) | | 分类描述 |

## 3. 资产明细 (asset_item)
存储用户的具体资产记录。

| 字段名 | 类型 | 约束 | 描述 |
| :--- | :--- | :--- | :--- |
| id | bigint | PK, AUTO_INCREMENT | 唯一标识 |
| user_id | bigint | FK, NOT NULL | 用户 ID |
| category_id | int | FK, NOT NULL | 分类 ID |
| asset_name | varchar(100) | NOT NULL | 资产名称 |
| current_value | decimal(18,2) | NOT NULL | 当前市值 |
| holding_cost | decimal(18,2) | | 持仓成本 |
| asset_code | varchar(50) | | 资产代码 |
| update_time | datetime | DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP | 更新时间 |

## 4. 风险测评 (risk_assessment)
记录用户的风险偏好测试结果。

| 字段名 | 类型 | 约束 | 描述 |
| :--- | :--- | :--- | :--- |
| id | bigint | PK, AUTO_INCREMENT | 唯一标识 |
| user_id | bigint | FK, NOT NULL | 用户 ID |
| total_score | int | | 总分 |
| risk_level | varchar(20) | | 风险等级 (稳健/平衡等) |
| assessment_json | text | | 存储答案详情 (JSON) |
| assess_date | datetime | DEFAULT CURRENT_TIMESTAMP | 测评日期 |

## 5. 投资计划 (investment_plan)
存储用户的投资计划（定投、单笔、目标）。

| 字段名 | 类型 | 约束 | 描述 |
| :--- | :--- | :--- | :--- |
| id | bigint | PK, AUTO_INCREMENT | 唯一标识 |
| user_id | bigint | FK, NOT NULL | 用户 ID |
| plan_type | tinyint | | 计划类型 (1-单笔/2-定投/3-目标) |
| target_amount | decimal(18,2) | | 目标金额 |
| current_amount | decimal(18,2) | | 当前已投金额 |
| frequency | varchar(50) | | 执行频率 (如: 每月) |
| next_execute_date | date | | 下次执行日期 |
| status | tinyint | | 状态 (0-进行, 1-完成) |

## 6. AI 交互记录 (ai_log)
记录与 AI 助手的交互历史。

| 字段名 | 类型 | 约束 | 描述 |
| :--- | :--- | :--- | :--- |
| id | bigint | PK, AUTO_INCREMENT | 唯一标识 |
| user_id | bigint | FK, NOT NULL | 用户 ID |
| module_context | varchar(100) | | 来自哪个页面/模块 |
| prompt_text | text | | 用户输入的 Prompt |
| response_text | text | | AI 返回的内容 |
| create_time | datetime | DEFAULT CURRENT_TIMESTAMP | 记录时间 |
