# 20260203_资产录入与统计功能开发

## 1. 任务背景
实现资产模块的核心功能：资产分类查询、资产明细录入、资产组合统计。

## 2. 资产体检计算公式
### 2.1 总资产规模
```
totalAmount = Σ(asset_item.current_value)
```

### 2.2 配置占比
```
categoryRatio = (Σ categoryAssets.current_value / totalAmount) × 100%
```

### 2.3 理性投资红线
```
investmentLimit = totalAmount × 20%
```
> 含义：单一品种的持仓不应超过总资产的 20%，以分散风险。

## 3. 核心接口 Request Body 示例
### POST /api/asset/add
```json
{
  "categoryId": 3,
  "assetName": "贵州茅台",
  "currentValue": 50000.00,
  "holdingCost": 45000.00,
  "assetCode": "600519"
}
```

### GET /api/asset/summary 响应示例
```json
{
  "code": 200,
  "data": {
    "totalAmount": 150000.00,
    "categoryDistribution": {
      "现金": 20.00,
      "固收": 30.00,
      "权益": 40.00,
      "保障": 5.00,
      "其他": 5.00
    },
    "investmentLimit": 30000.00
  }
}
```

## 4. 前端表单校验逻辑
| 字段 | 规则 | 提示 |
|:---|:---|:---|
| categoryId | 必填 | 请选择资产分类 |
| assetName | 必填, 2-50 字符 | 资产名称长度必须在2-50之间 |
| currentValue | 必填, > 0 | 当前市值必须大于0 |
