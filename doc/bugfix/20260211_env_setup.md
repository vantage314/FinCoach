# 环境变量配置说明 (Phase 1)

为避免提交敏感信息，后端配置已改为从环境变量读取。请在运行后端前设置以下变量：

## 必需 (生产/演示)
- `DB_URL`：数据库连接串  
  示例：`jdbc:mysql://localhost:3306/fincoach?useUnicode=true&characterEncoding=utf-8&useSSL=false&serverTimezone=GMT%2B8&allowPublicKeyRetrieval=true`
- `DB_USERNAME`：数据库用户名  
  示例：`root`
- `DB_PASSWORD`：数据库密码
- `DEEPSEEK_API_KEY`：DeepSeek API Key

## 可选 (有默认值)
- `DEEPSEEK_BASE_URL`：默认 `https://api.deepseek.com`
- `DEEPSEEK_MODEL`：默认 `deepseek-chat`

说明：
- 未配置 `DB_PASSWORD` 或 `DEEPSEEK_API_KEY` 将导致运行时连接/调用失败，但不影响编译。
