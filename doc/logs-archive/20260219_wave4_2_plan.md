# Wave4.2 Crawler Self-Heal Plan (2026-02-19)

## States
- STOPPED
- RUNNING
- STARTING (optional transitional)
- STOPPING (optional transitional)

## Derived State
- STALE (derived only, not persisted)
  - Condition: `status == RUNNING` AND `now - lastHeartbeatAt > staleThresholdSeconds`

## Idempotency Rules
- START
  - RUNNING and not STALE => 200 "already running"
  - RUNNING and STALE => recover (mark old run ended, start new)
  - STOPPED => start new run
- STOP
  - STOPPED => 200 "already stopped"
  - STOPPING => 200 "stop in progress"
  - RUNNING => request stop; runner transitions to STOPPED

## Concurrency Guard
- Single active daemon per environment.
- Enforce via DB row lock on job status (select row FOR UPDATE) or optimistic version.

## Log Policy
- `last_log` truncated to max N chars (e.g., 4000).
- Append semantics include timestamp + level.
