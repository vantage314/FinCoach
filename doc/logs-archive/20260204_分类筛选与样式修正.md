# 20260204_分类筛选与样式修正

## 1. 后端查询逻辑升级
### 新增 DTO
```java
public class AssetQueryDTO {
    private Integer categoryId;  // 分类ID
    private String assetName;    // 名称关键字
}
```

### Service 条件查询
```java
wrapper.eq(query.getCategoryId() != null, AssetItem::getCategoryId, query.getCategoryId());
wrapper.like(StringUtils.hasText(query.getAssetName()), AssetItem::getAssetName, query.getAssetName());
```

### Controller 参数
```
GET /api/asset/list?categoryId=2&assetName=茅台
```

## 2. 前端搜索栏改造
在 Dashboard 搜索栏添加 `el-select` 分类下拉：
- 选项来自 `getCategories()` 接口
- 选择分类后触发 `@change="handleSearch"`
- 支持 `clearable` 清除选择

API 调用改为后端筛选：
```typescript
const params = {
  categoryId: selectedCategory.value,
  assetName: searchKeyword.value
};
await getAssetList(params);
```

## 3. 弹窗样式修正 (White Mode)
### 决策原因
Glassmorphism 深色背景导致输入框文字不可见。

### CSS 修改
```scss
:deep(.el-input__wrapper) {
  background-color: #ffffff !important;
  box-shadow: 0 0 0 1px #dcdfe6 inset !important;
}
:deep(.el-input__inner) {
  color: #000000 !important;
  font-weight: 500;
}
```
