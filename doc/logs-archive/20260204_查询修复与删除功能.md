# 20260204_查询修复与删除功能

## 1. MyBatis Plus 动态查询正确写法
```java
LambdaQueryWrapper<AssetItem> wrapper = new LambdaQueryWrapper<>();
// 基础围栏：强制 userId 条件（防止越权）
wrapper.eq(AssetItem::getUserId, userId);

// 动态条件：仅当 categoryId 不为 null 时追加
wrapper.eq(query.getCategoryId() != null, AssetItem::getCategoryId, query.getCategoryId());

// 动态条件：仅当 assetName 有文本时追加模糊查询
wrapper.like(StringUtils.hasText(query.getAssetName()), AssetItem::getAssetName, query.getAssetName());

wrapper.orderByDesc(AssetItem::getUpdateTime);
```

## 2. 批量删除越权防御逻辑
**错误做法**：直接调用 `removeByIds(ids)` → 可能删除他人资产

**正确做法**：
```java
LambdaQueryWrapper<AssetItem> wrapper = new LambdaQueryWrapper<>();
wrapper.in(AssetItem::getId, ids)
       .eq(AssetItem::getUserId, userId);  // 关键：只能删自己的

int rows = assetItemMapper.delete(wrapper);
```
