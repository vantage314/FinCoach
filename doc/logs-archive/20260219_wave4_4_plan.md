# Wave4.4 Plan — Configurable Advice Engine & Rebalance Suggestions

## Why Config
- Allow tuning rebalance thresholds, risk bands, and behavior scoring weights without code changes.
- Support controlled rollouts via ruleset versioning and enable switch.

## Data Model
- RuleSet:
  - code
  - version
  - enabled
  - description
  - createdAt
- RuleParam:
  - ruleSetCode
  - key
  - value
  - type
  - updatedAt

## Definition of Done
- API for reading active rules
- Admin CRUD + enable switch
- Rebalance suggestions produced from active rules
- Tests cover fallback to default
