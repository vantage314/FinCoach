## 1. 四维健康模型

### 评分标准 (总分 100)

| 维度 | 满分 | 评分规则 |
|:---|:---:|:---|
| **流动性** | 20 | 现金类占比 ≥10% 满分，5-10% 扣8分，<5% 扣15分 |
| **风险匹配** | 40 | 偏差 ≤10% 满分，每超5% 扣5分，无测评给满分 |
| **保障力** | 20 | 有固定资产满分，无则10分 |
| **分散度** | 20 | ≥3类满分，2类14分，1类5分 |

### 健康等级
- **优秀**: 80-100 分
- **良好**: 60-79 分
- **一般**: 40-59 分
- **待优化**: <40 分

## 2. 后端实现

### 文件清单
| 文件 | 类型 | 说明 |
|:---|:---|:---|
| `HealthReportVO.java` | VO | 体检报告响应对象 |

## 3. 前端联动机制

### Pinia Store (`store/modules/health.ts`)
```typescript
const healthStore = useHealthStore();
await healthStore.fetchHealthReport();
```

### Dashboard 联动刷新
```typescript
const refreshData = async () => {
  await Promise.all([
    fetchAssets(),
    fetchSummary(),
    healthStore.fetchHealthReport() // 联动刷新
  ]);
};
```

### 触发时机
- 页面加载时
- 新增资产后
- 删除资产后
- 点击健康卡片时（手动刷新）
