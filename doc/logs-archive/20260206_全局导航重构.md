# 路由渲染与数据加载修复 - 2026年2月6日

## 变更概述

修复导航切换时组件重新渲染问题，增强数据加载逻辑。

---

## 关键修复

### 1. TopLayout 组件 Key 绑定

```diff
- <component :is="Component" />
+ <component :is="Component" :key="$route.fullPath" />
```

**原理**：路径变化时强制销毁旧组件并重新创建，确保 `onMounted` 每次都触发。

---

### 2. Dashboard 生命周期增强

```typescript
// 封装数据加载逻辑
const loadData = () => {
  fetchCategories();
  refreshData();
  fetchRiskResult();
};

// 组件挂载时加载
onMounted(() => loadData());

// 双重保险：KeepAlive 激活时也刷新
onActivated(() => loadData());
```
