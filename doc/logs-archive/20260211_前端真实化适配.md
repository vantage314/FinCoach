# 前端真实化适配 - 2026-02-11

## 概述
将前端从硬编码假数据改为显示后端真实数据。

## 变更清单

### 1. 市场中心 `Index.vue`
- **新闻栏真实化**: 从硬编码5条假新闻改为调用 `getNewsList` API 获取真实新闻
- **新闻自动刷新**: 每120秒从后端刷新新闻数据
- **停牌处理**: 价格为0或涨跌幅为0时,显示"停牌"灰色文字
- **涨跌色A股规范**: 红涨(+600)绿跌(-600),灰色停牌,字体加粗
- **价格格式化**: `formatPrice()` 和 `formatChange()` 统一格式

### 2. 股票详情页 `StockDetail.vue`
- **价格区域动态化**: 从硬编码 `180.50 ↑ +3.20%` 改为 `stockData` 响应式对象
- **3秒轮询**: `fetchRealPrice()` 每3秒从 `/api/market/detail/{code}` 获取最新价
- **状态标签动态**: 交易中/停牌/加载中 根据实际数据动态切换
- **盘口占位**: 五档盘口暂用 `--` 占位,后续接入真实五档

### 3. 后端新增接口
- `MarketController.getSecurityDetail`: `GET /api/market/detail/{code}`
- `MarketService.getSecurityByCode`: 按证券代码查询单条记录
- `MarketServiceImpl`: LambdaQueryWrapper 实现

### 4. Maven 编译修复
- 添加 `maven-compiler-plugin 3.11.0` 配置
- 添加 `maven.compiler.source/target=17`
- 清空 `maven.compiler.release` 避免 Spring Boot parent 注入 `--release`
- 修复 `Result.error` 方法签名: `error(404, msg)` 而非 `error(msg)`
- **重要**: 编译时需设置 `JAVA_HOME=D:\software\jdk21`

## 编译验证
```
$env:JAVA_HOME = "D:\software\jdk21"
mvn compile -q  # Exit code: 0 ✅
```
