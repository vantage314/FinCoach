# 20260203_Swagger 接入及接口规范化

## 1. 任务背景
在 Spring Boot 3 工程中集成 SpringDoc OpenAPI 3，建立自动化接口文档体系并制定 API 开发规范。

## 2. 完成点
- **依赖引入**: 引入 `springdoc-openapi-starter-webmvc-ui:2.3.0`。
- **环境配置**:
    - 接口定义地址: `/v3/api-docs`
    - Swagger UI 地址: `/swagger-ui.html`
- **安全准入改动**:
    - 更新 `AuthInterceptor.java`，将 Swagger 相关路径加入白名单。
- **接口文档化样例**:
    - 完成 `AuthController` 注册与登录接口的注解补全。
    - 完成 `Result` 统一返回类的 Schema 描述。

## 3. 访问信息
- **本地 Swagger UI**: `http://localhost:8080/swagger-ui.html`
