## 6. Phase 4.6 知行合一诊断模型

### 核心算法
```
idealRatio = riskLevel.getEquityLimit()  // 理想权益占比
actualRatio = 权益类资产 / 总资产          // 实际权益占比
gap = actualRatio - idealRatio            // 偏差值
```

### 诊断规则
| 条件 | 诊断文案 |
|:---|:---|
| gap < -0.2 | ⚠️ 配置过于保守，建议增加权益类投资 |
| gap > 0.1 | 🔴 风险敞口超标，建议增加固收配置 |
| 其他 | ✅ 知行合一，配置完美匹配 |

### 容错处理
- 总资产为 0：actualRatio = 0，提示"请先完善资产档案"
