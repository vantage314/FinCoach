# 市场中心体验精修与深度数据扩展 - 2026年2月6日

## 变更概述
Phase 6.3 重点优化了用户体验和数据的专业度，包括 UI 的暗黑模式深度适配、海量数据的分页浏览能力，以及个股详情页的专业指标展示。

---

## 功能变更详情

### 1. UI 样式覆盖 (CSS Override)
- **文件**: `frontend/src/theme/element-overwrite.scss`
- **内容**: 
  - 强制覆盖 `.el-dialog` 样式，背景改为 `rgba(30, 41, 59, 0.95)`，增加 `backdrop-filter` 效果。
  - 适配 `.el-pagination` 样式，使其在深色背景下不突兀。

### 2. 行情列表 (Market List)
- **Store**: `useMarketStore` 增加 `total`, `currentPage`, `pageSize` 状态，`fetchSecurities` 支持分页切片逻辑。
- **UI**: 
  - 底部增加 `<el-pagination>`。
  - 风险等级列 (`column`) 增加 `<el-tooltip>`，悬停显示详细风险释义。

### 3. 数据层扩展 (Data Layer)
- **Database**: 增加 `SQL/20260206_security_details.sql` 脚本，扩展 `market_cap`, `pe_ratio`, `volume`, `high52w`, `low52w` 字段。
- **Mock Data**: 更新 `market.ts` 中的 Mock 数据，为茅台、腾讯、苹果等头部资产补充真实感更强的财务指标。

### 4. 证券详情页 (Security Detail)
- **信息区**: 增加 3 列布局展示扩展字段（市值、PE、成交量、52周范围）。
- **K线图表**: 
  - 新增 K 线周期切换 Tab (Day/Week/Month)。
  - `generateMockData` 算法升级，根据不同周期生成不同波动率和趋势的数据，模拟真实行情特征。

---

## 验证结果 (Self-verification)
- **弹窗 UI**: 新闻弹窗背景色正确，不再是白色。
- **分页**: 点击第 2 页，表格数据发生变化（由于Mock数据总量52，第2页应为第11-20条）。
- **详情页**: 
  - 能够看到"市值：2.1万亿"等信息。
  - 切换"周K"后，折线图变平滑，数据点变少，符合预期。
