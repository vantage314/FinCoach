# Wave4.9 Ops Log — Bulk Import + Notifications UX

## Scope
- Debt/Cashflow CSV 导入：解析 + 行级校验 + 错误回传
- 导入幂等：Debt 使用 externalKey，Cashflow 按 (user_id, month) upsert
- 前端导入 UI：模板下载、结果汇总、错误表格
- 通知 UX：顶部铃铛、未读数、通知列表页（全量/未读 + 全部已读）

## Backend Changes
- 新增导入服务：Debt/CashflowMonth CSV 解析与校验
- fc_debt 增加 external_key 字段（导入幂等）
- 导入接口：
  - POST `/api/app/debt/importCsv`
  - POST `/api/app/cashflow/importCsv`

## Frontend Changes
- Debt/Cashflow 页面加入 CSV 导入入口 + 模板下载 + 结果弹窗
- 顶部通知铃铛 + 未读数 + 最新 10 条
- 新增通知中心页面 `/app/notifications`

## CSV Templates
Debt CSV:
```
debtType,apr,remainingBalance,monthlyPayment,termMonths,principal,startDate,endDate,externalKey
MORTGAGE,0.045,480000,3200,240,500000,2022-01-01,2042-01-01,loan-001
```

Cashflow CSV:
```
month,income,expense
2026-01,12000,8000
```

## Verification (curl)
```
# Debt import
curl -X POST -F "file=@debt.csv" http://localhost:5173/api/app/debt/importCsv

# Cashflow import
curl -X POST -F "file=@cashflow.csv" http://localhost:5173/api/app/cashflow/importCsv

# Notifications list
curl "http://localhost:5173/api/app/notifications?page=1&size=20"

# Mark read
curl -X PUT http://localhost:5173/api/app/notifications/{id}/read

# Mark all read
curl -X PUT http://localhost:5173/api/app/notifications/read-all
```

## Validation Errors (examples)
- `debtType 不能为空`
- `apr 必须大于等于0`
- `month 格式需为 YYYY-MM 或 YYYY-MM-DD`
