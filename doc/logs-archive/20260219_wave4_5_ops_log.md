# Wave4.5 Ops Log — Debt + Cashflow Integration

## Scope
- DB: add `fc_debt` and `fc_cashflow_month` tables.
- API: debt/cashflow CRUD under `/api`.
- HealthV2: scoring integrates DTI, emergency fund months, and cashflow stability with warnings.
- Advice: add `debtSuggestions` and `cashflowSuggestions` using configurable thresholds.
- Config defaults (Advice ruleset):
  - `DTI_WARN` = 0.35
  - `DTI_DANGER` = 0.50
  - `EMERGENCY_FUND_MONTHS_TARGET` = 3

## Verification (curl examples)
Assume `TOKEN` is a valid user token.

- Debt upsert:
```bash
curl -X POST "http://localhost:8080/api/debt/upsert" \
  -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{"debtType":"CREDITCARD","principal":5000,"apr":0.18,"remainingBalance":3500}'
```

- Debt list:
```bash
curl -X GET "http://localhost:8080/api/debt/list" \
  -H "Authorization: Bearer $TOKEN"
```

- Debt delete (soft delete):
```bash
curl -X POST "http://localhost:8080/api/debt/delete" \
  -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{"id":1}'
```

- Cashflow upsert:
```bash
curl -X POST "http://localhost:8080/api/cashflow/upsertMonth" \
  -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{"month":"2026-02","income":12000,"expense":8000}'
```

- Cashflow list:
```bash
curl -X GET "http://localhost:8080/api/cashflow/months?from=2026-01&to=2026-03" \
  -H "Authorization: Bearer $TOKEN"
```

- Advice output (includes new fields):
```bash
curl -X GET "http://localhost:8080/api/advice/rebalance" \
  -H "Authorization: Bearer $TOKEN"
```
Check JSON includes:
- `debtSuggestions[]`
- `cashflowSuggestions[]`

- Health report metrics include new sections:
```bash
curl -X GET "http://localhost:8080/api/app/health-reports/latest" \
  -H "Authorization: Bearer $TOKEN"
```
Check `metrics.cashflow`, `metrics.debt`, `metrics.emergencyFund` exist.
