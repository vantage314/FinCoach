# Wave4.3 Observability Plan (2026-02-19)

## Why Tail Truncation
- Keeping the tail preserves the newest operational signals and errors.
- Operators typically need the most recent events when debugging.

## Event Ring
- Size: N=20 events
- Fields per event:
  - ts (timestamp)
  - type (event type)
  - msg (short message)

## Counters
- restartCount
- staleCount
- recoverCount
- lastErrorAt

## UI Additions
- Recent events table (ts/type/message)
- Counters display (stale/recover/restart)
