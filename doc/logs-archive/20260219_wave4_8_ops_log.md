# Wave4.8 Ops Log — Alerts & Notifications Center

## Scope
- Added alerts + notifications tables (fc_alert, fc_notification).
- Added alert dedupe service with OPEN/ACKED/RESOLVED lifecycle.
- Emitted alerts from HealthV2 warnings and crawler stale events.
- Added alerts/notifications APIs and admin alerts page updates.

## Dedupe Rules
- dedupeKey = userId + ':' + alertType (userId null => SYSTEM).
- If OPEN alert exists, update lastSeenAt + hitCount and overwrite message/meta.
- New OPEN or severity escalation emits a new notification for the user.

## Endpoints
User:
- GET  /api/app/alerts/list?status=OPEN
- GET  /api/app/notifications/list
- POST /api/app/notifications/read {id}
- POST /api/app/notifications/readAll

Admin:
- GET  /admin/api/alerts/list?status=OPEN&type=&severity=&userId=
- POST /admin/api/alerts/ack
- POST /admin/api/alerts/resolve

## Verification (curl examples)
```bash
# user alerts
curl -X GET "http://localhost:8080/api/app/alerts/list?status=OPEN" -H "Authorization: Bearer <TOKEN>"

# notifications list
curl -X GET "http://localhost:8080/api/app/notifications/list" -H "Authorization: Bearer <TOKEN>"

# mark single read
curl -X POST "http://localhost:8080/api/app/notifications/read" \
  -H "Authorization: Bearer <TOKEN>" -H "Content-Type: application/json" \
  -d '{"id":1}'

# mark all read
curl -X POST "http://localhost:8080/api/app/notifications/readAll" -H "Authorization: Bearer <TOKEN>"

# admin list
curl -X GET "http://localhost:8080/admin/api/alerts/list?status=OPEN" -H "Authorization: Bearer <ADMIN_TOKEN>"

# admin ack/resolve
curl -X POST "http://localhost:8080/admin/api/alerts/ack" \
  -H "Authorization: Bearer <ADMIN_TOKEN>" -H "Content-Type: application/json" \
  -d '{"alerts":[{"alertId":1}]}'

curl -X POST "http://localhost:8080/admin/api/alerts/resolve" \
  -H "Authorization: Bearer <ADMIN_TOKEN>" -H "Content-Type: application/json" \
  -d '{"alerts":[{"alertId":1}]}'
```

## Notes
- Premium ratio warn/danger uses threshold from insurance gap metrics; danger = threshold * 2.
- Crawler stale detection emits CRAWLER_STALE_DETECTED and CRAWLER_STALE_RECOVERED alerts (system-level).
