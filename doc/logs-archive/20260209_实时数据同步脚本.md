# 20260209 - 实时数据同步脚本开发

## 完成内容

### 创建 market_updater.py
- 位置: `d:\project\FinCoach\market_updater.py`
- 功能:
  1. **实时行情更新**: 每 5 秒获取 A 股实时行情（东方财富数据源），更新 `market_security` 表中已有股票的价格和涨跌幅
  2. **财经新闻获取**: 每 1 分钟获取财联社电报，自动去重后存入 `financial_news` 表

### 技术栈
- akshare: 金融数据获取
- pandas: 数据处理
- sqlalchemy + pymysql: 数据库连接
- schedule: 定时任务调度

## 脚本特性
- 智能过滤: 只更新数据库中已有股票，节省 API 调用
- 自动去重: 新闻通过内容哈希去重，防止重复插入
- 稳定运行: 异常捕获防止单次失败导致服务中断
- 连接池: 数据库连接复用，提升性能
