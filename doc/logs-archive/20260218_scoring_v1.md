# Scoring v1 (Risk / Asset Health / Behavior)

## Context
Scoring v1 adds explainable outputs for risk, asset health, and behavior scores with configurable weights and thresholds. The goal is to keep existing formulas intact while making missing inputs visible via warnings and supporting admin/debug observability.

## Score Formulas (Overview)
- Risk score: weighted sum of Sharpe, max drawdown, volatility, and diversification risk (weights from rule set).
- Asset health score: weighted sum of liquidity, debt health, diversification, risk-adjusted return, and behavior.
- Behavior score: 30-day activity baseline with cashflow adjustments.

Each score outputs `value`, `level`, `breakdown`, and `warnings`.

## Config Keys
Rule set parameters used (with defaults in `ScoreRuleDefaults`):
- `W_SHARPE`, `W_MDD`, `W_VOL`, `W_DIVERSIFICATION`
- `SHARPE_OK`, `SHARPE_GOOD`, `MDD_OK`, `MDD_BAD`
- `CASH_FLOW_RATE_MIN`, `DEBT_RATIO_MAX`, `EMERGENCY_MONTHS_MIN`
- `ASSET_LIABILITY_RATIO_GOOD`, `LIQUIDITY_RATIO_GOOD`
- `HEALTH_W_LIQUIDITY`, `HEALTH_W_DEBT`, `HEALTH_W_DIVERSIFICATION`, `HEALTH_W_RAR`, `HEALTH_W_BEHAVIOR`
- `RISK_LEVEL_HIGH_MIN`, `RISK_LEVEL_MED_MIN`
- `HEALTH_LEVEL_HIGH_MIN`, `HEALTH_LEVEL_MED_MIN`
- `BEHAVIOR_LEVEL_HIGH_MIN`, `BEHAVIOR_LEVEL_MED_MIN`

## Degrade / Warnings
Missing inputs do not throw. Common warnings:
- `SCORE_MISSING_SHARPE`, `SCORE_MISSING_MDD`, `SCORE_MISSING_VOLATILITY`
- `SCORE_MISSING_ALLOCATION`, `SCORE_MISSING_TOTAL_ASSETS`
- `SCORE_MISSING_CASHFLOW`, `SCORE_MISSING_LIABILITIES`
- `SCORE_BEHAVIOR_DATA_UNAVAILABLE`

Rule set fallback/missing params warnings are included via the rule snapshot.
