# Wave4.7 Ops Log — Insurance Gap Assessment

## Scope
- Added insurance profile and config tables.
- Added user profile CRUD and admin config APIs.
- Integrated insurance gaps and premium ratio into HealthV2 metrics + warnings.
- Added insuranceSuggestions with priority rules in advice output.

## Schema
- fc_insurance_profile
  - user_id (unique), annual_income, annual_premium_total, dependents, age
  - existing_cover_medical/accident/ci/life
  - updated_at
- fc_insurance_config
  - code (DEFAULT), target_medical/accident/ci
  - target_life_multiplier
  - premium_ratio_warn / premium_ratio_danger
  - updated_at

## Endpoints
User:
- GET  /api/app/insurance/profile
- POST /api/app/insurance/profile/upsert

Admin:
- GET  /admin/api/insurance/config
- POST /admin/api/insurance/config/upsert

## Verification (curl examples)
```bash
# user profile
curl -X GET "http://localhost:8080/api/app/insurance/profile" -H "Authorization: Bearer <TOKEN>"

curl -X POST "http://localhost:8080/api/app/insurance/profile/upsert" \
  -H "Authorization: Bearer <TOKEN>" -H "Content-Type: application/json" \
  -d '{"annualIncome":120000,"annualPremiumTotal":12000,"dependents":1,"existingCoverMedical":100000}'

# admin config
curl -X GET "http://localhost:8080/admin/api/insurance/config" -H "Authorization: Bearer <ADMIN_TOKEN>"

curl -X POST "http://localhost:8080/admin/api/insurance/config/upsert" \
  -H "Authorization: Bearer <ADMIN_TOKEN>" -H "Content-Type: application/json" \
  -d '{"targetMedical":500000,"targetAccident":500000,"targetCi":500000,"targetLifeMultiplier":5,"premiumRatioWarn":0.10,"premiumRatioDanger":0.20}'

# health/advice fields
curl -X GET "http://localhost:8080/api/app/health/report" -H "Authorization: Bearer <TOKEN>"
curl -X GET "http://localhost:8080/api/advice/rebalance" -H "Authorization: Bearer <TOKEN>"
```

## Metrics & Warnings
- metrics.insurance: medicalGap, accidentGap, ciGap, lifeGap, lifeTarget, premiumRatio
- Warnings:
  - INCOME_MISSING_FOR_PREMIUM_RATIO
  - PREMIUM_RATIO_WARN / PREMIUM_RATIO_DANGER
  - INSURANCE_GAP_HIGH

## Defaults
- target_life_multiplier = 5
- premium_ratio_warn = 0.10
- premium_ratio_danger = 0.20
