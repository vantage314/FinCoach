# 任务日志 - 2026-02-07 智能投资驾驶舱前端开发

## Phase 12.2: Frontend Development

### 1. API 封装 (frontend/src/api/invest.ts)
- 封装了 5 个核心接口，对接 Phase 12.1 的后端服务：
    - `getNewsList`: 获取新闻流
    - `getNewsDetail`: 获取新闻详情
    - `getCompanyProfile`: 获取 F10 资料
    - `getWatchlist`: 获取自选股代码列表
    - `toggleWatchlist`: 切换自选状态

### 2. 页面开发 (frontend/src/views/investment/Index.vue)
- **布局架构**：
    - 采用 **左右分栏** 布局，左侧为自选股列表，右侧为机会雷达与推荐池。
- **左侧：我的自选**：
    - 展示用户关注的股票列表（代码、名称、现价、涨跌幅）。
    - 支持 **一键移除** 自选。
    - 点击股票项跳转至详情页。
- **右侧：市场机会**：
    - **市场雷达**：4 个板块卡片（新能源、半导体、房地产、人工智能），模拟涨跌幅与热点描述。
    - **今日潜力机会**：
        - 自动筛选涨幅 > 0 的股票。
        - 按涨幅降序排列 Top 5。
        - 支持 **一键关注**，状态实时同步（已关注/未关注）。

### 3. 路由注册 (frontend/src/router/index.ts)
- 新增路由 `/investment`：
    ```typescript
    {
        path: '/investment',
        name: 'Investment',
        component: () => import('@/views/investment/Index.vue'),
        meta: { title: '智能投资驾驶舱', requiresAuth: true }
    }
    ```

## 验证结论
- **数据联动**：前端能正确拉取后端注入的 F10、新闻和自选数据。
- **交互闭环**：
    - 在“今日机会”点击“+关注”，左侧自选列表即时刷新并追加该股票。
    - 在左侧点击“删除”图标，股票即时移除，且右侧按钮恢复为“+关注”。
- **路由跳转**：点击股票名称能正确跳转至 `/market/detail/:code`。
