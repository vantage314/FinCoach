## 实施内容

### 1. 后端 Python 脚本 ✅

#### 新建文件
- **`market_updater_final.py`**：终极兜底版市场数据同步脚本

#### 核心功能

**模式 A：真实数据获取**
- 优先调用 `akshare.stock_zh_a_spot()` 获取新浪源数据
- 成功则更新数据库 `market_security` 表
- 失败自动降级到模式 B

**模式 B：仿真兜底**
- 从数据库读取 `current_price`
- 生成随机波动：`fluctuation = random.uniform(0.995, 1.005)`
- 计算模拟涨跌幅并更新数据库
- 控制台输出：`"⚠️ 网络/接口异常，切换仿真..."`

**新闻模块容错**
- 使用 `try-except` 包裹新闻获取逻辑
- 失败时 `pass`，不中断主程序

**循环频率**
- 行情更新：每 **5 秒**
- 新闻更新：每 **2 分钟**

## 已解决的问题

### 1. akshare IP 被封
**原因：** 高频请求导致数据源封禁  
**解决：** 降低请求频率（15s → 5s）+ 仿真兜底

### 2. 前端全屏 Loading
**原因：** 每次轮询都触发 `loading.value = true`  
**解决：** 添加 `silent` 参数控制 Loading 状态

### 3. TypeScript 类型错误
**原因：** `market.ts` 缺少类型导出  
**解决：** 添加 `Security`、`MarketNews`、`MarketIndex` 接口
