# Wave4.8 Plan — Alerts & Notifications Center

## Alert Sources
- Crawler:
  - CRAWLER_STALE_DETECTED
  - CRAWLER_STALE_RECOVERED
- HealthV2:
  - DTI_DANGER / DTI_WARN
  - CASHFLOW_NEGATIVE (avgNet < 0 or 2 consecutive months < 0)
  - EMERGENCY_FUND_LOW / EMERGENCY_FUND_CRITICAL
  - PREMIUM_RATIO_WARN / PREMIUM_RATIO_DANGER
  - INSURANCE_GAP_HIGH

## Alert Lifecycle
- OPEN -> ACKED -> RESOLVED

## Channels
- IN_APP (user-facing)
- ADMIN_DASHBOARD

## Dedupe Policy
- Same user + same type within window updates existing alert:
  - update lastSeenAt
  - increment hitCount
  - update message/meta to latest
