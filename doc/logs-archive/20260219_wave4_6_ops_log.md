# Wave4.6 Ops Log — UI: Debt & Cashflow Entry + Trends

## UI Routes
- `/app/debt` 债务管理
- `/app/cashflow` 现金流管理

## APIs Used
- `GET  /api/app/debt/list`
- `POST /api/app/debt/upsert`
- `POST /api/app/debt/delete`
- `GET  /api/app/cashflow/months?from=YYYY-MM&to=YYYY-MM`
- `POST /api/app/cashflow/upsertMonth`
- `GET  /api/app/health-reports/latest` (诊断页读取告警)

## Manual Verification Checklist
- 访问 `/app/debt` 页面，列表加载成功。
- 新增债务 -> 列表出现；编辑保存成功；删除后列表移除。
- 访问 `/app/cashflow` 页面，选择月份范围查询。
- 新增现金流月份 -> 列表出现；编辑保存成功。
- 现金流趋势图可显示净结余折线。
- 债务结构图显示分布（按类型汇总剩余本金）。
- 诊断页在出现 `CASHFLOW_INSUFFICIENT_DATA` / `EMERGENCY_FUND_UNKNOWN` / `DTI_INSUFFICIENT_INCOME` 时展示跳转按钮，点击能进入 `/app/debt` 与 `/app/cashflow`。
