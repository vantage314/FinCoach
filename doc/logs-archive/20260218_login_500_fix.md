# 2026-02-18 Login 500 Fix

## 问题
- `POST /api/auth/login` 在用户名或密码错误时返回 500（前端显示 code=500），而不是 401。

## 根因
- `AuthServiceImpl.login` 抛出 `RuntimeException`，被 `GlobalExceptionHandler` 统一映射为 500。
- `AuthDTO` 未启用参数校验，缺字段或空字段时缺少 400 映射路径。

## 修复
- 新增 `UnauthorizedException` 并在 `GlobalExceptionHandler` 映射为 HTTP 401 + code=401。
- `AuthServiceImpl.login` 对用户名/密码错误抛 `UnauthorizedException`。
- `AuthDTO` 增加 `@NotBlank/@Size`，`AuthController.login` 增加 `@Valid`。
- 增加请求体解析失败（空体/非法 JSON）的 400 映射。
- 增加开发日志：登录 DTO 的空字段判定日志（不输出明文密码）。

## 回归测试
- `AuthControllerTest`：
- 正确账号密码 -> 200 + token 非空
- 错误密码 -> 401
- 缺 username/password -> 400

## 说明
- 未引入新依赖、未变更数据库 schema。
- 登录成功仍返回 token，失败返回 400/401/403 而非 500。
