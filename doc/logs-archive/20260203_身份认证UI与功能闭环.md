# 20260203_身份认证UI与功能闭环

## 1. 任务背景
实现用户系统的第一步：登录与注册的视觉呈现及核心逻辑打通。

## 2. 视觉设计 (UX/UI)
- **风格**: 玻璃拟态 (Glassmorphism)。
- **背景**: 深蓝到暗青的径向渐变，辅以动态模糊光晕。
- **卡片**: `backdrop-filter: blur(20px)`，半透明边框，柔和阴影。
- **交互**: 按钮缩放动画及发光悬停效果。

## 3. 技术实现
- **布局**: `AuthLayout.vue` 统一管理认证背景。
- **验证**:
    - 用户名: 必填, 最小 3 位。
    - 密码: 必填, 最小 6 位。
    - 注册特有: 两次密码一致性校验。
- **存储**: 使用 `localStorage` 进行 JWT Token 的持久化。
- **路由**:
    - 配置 `/login`, `/register`。
    - 增加全局路由守卫 `beforeEach`，根据 `localStorage` 中的 token 状态执行重定向。

## 4. 接口对接
- **登录**: `POST /api/auth/login`
- **注册**: `POST /api/auth/register` (明文传输至后端加密)。
