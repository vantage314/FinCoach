# 市场中心数据扩容与交互增强 - 2026年2月6日

## 变更概述
完成 Phase 6.2 开发任务，重点扩充了市场数据并增强了用户交互体验。

---

## 功能变更

### 1. 数据扩容 (Data Expansion)
- **Market Store**: 扩充 `mockSecurities` 至 52 条，涵盖：
  - 白酒（茅台、五粮液）
  - 科技/互联网（腾讯、阿里、百度、苹果、微软、英伟达）
  - 新能源（宁德时代、比亚迪、特斯拉）
  - 医疗（迈瑞、药明康德）
  - 基金/ETF（沪深300、科创50、半导体ETF）
  - 债券（国债、企业债）
- **Market API**: 更新 `MarketNews` 接口，增加 `content` 字段支持详情展示。

### 2. 搜索功能 (Search)
- **Store Logic**: `fetchSecurities` 支持 `{ keyword }` 参数，实现本地模糊过滤（匹配名称或代码）。
- **UI**: 行情列表顶部增加搜索输入框，支持回车和点击搜索。

### 3. 交互增强 (Interaction)
- **列表跳转**: 证券名称列改为蓝色链接样式，点击跳转 `/market/security/:id`。
- **新闻弹窗**: 点击滚动资讯栏弹出 Dialog，展示新闻全文、来源和时间。
