# 20260203_资产管理前端功能补齐记录

## 1. 任务背景
完成资产管理模块的前端功能，包括 API 封装、录入抽屉组件、Dashboard 资产列表展示。

## 2. 资产分类下拉框数据绑定逻辑
```typescript
// 组件挂载时自动调用
onMounted(() => {
  fetchCategories();
});

const fetchCategories = async () => {
  const res = await getCategories();
  if (res.code === 200) {
    categories.value = res.data; // 绑定到 el-select
  }
};
```

## 3. 前端表单字段校验规则
| 字段 | 规则 | 实现方式 |
|:---|:---|:---|
| categoryId | 必选 | `required: true` |
| assetName | 必填, 2-50字符 | `min: 2, max: 50` |
| currentValue | 必填, > 0 | `required: true` + 手动校验 |

校验代码示例：
```typescript
if (form.currentValue <= 0) {
  ElMessage.error('当前市值必须大于 0');
  return;
}
```

## 4. 父子组件间列表刷新机制
使用 `emit` 事件实现：
```typescript
// 子组件 AssetInputDrawer.vue
emit('success'); // 录入成功后触发

// 父组件 Dashboard/Index.vue
<AssetInputDrawer v-model="showDrawer" @success="refreshData" />

const refreshData = () => {
  fetchAssets();
  fetchSummary();
};
```

## 6. Token 自动携带验证
所有 API 调用经过 `request.ts` 拦截器，自动从 localStorage 读取 token 并添加到 Header：
```typescript
// request.ts 拦截器逻辑
const token = localStorage.getItem('token');
if (token) {
  config.headers['Authorization'] = `Bearer ${token}`;
}
```
